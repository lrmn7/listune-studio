# Lemo-Opuscar Film Styles Library

Lemo-Opuscar is a library of 66 film styles made in code. Every style is directed, drawn, animated and mixed in code without generative AI video artifacts.

## Style Categories

1. **Edit & Documentary**: Caption News (`caption-news`), 1920s Newsreel (`newsreel`), Live Countdown (`countdown`), Time-lapse Symphony (`city-symphony`), Visual Investigation (`visual-investigation`), Constructivist Montage (`kino-montage`), Sports Telestrator (`telestrator`), Broadcast News Package (`news-package`).
2. **Evidence Films**: Satellite Briefing (`satellite-briefing`), Engineering Briefing Board (`briefing-board`), LiDAR Survey (`lidar-survey`), Projection on White Model (`white-model`), Data Physicalization (`data-physical`), Exploded Teardown (`teardown`), Microscope Story (`microscope`), Archive Light Table (`archive-lighttable`).
3. **Hand-drawn & Painting**: Crayon Picture Book (`crayon-book`), Watercolor Brush (`watercolor`), Chinese Ink Wash (`ink-wash`), Impasto Oil Painting (`impasto`), One-line Drawing (`one-line`), Whiteboard Explainer (`whiteboard`), Urban Sketch (`urban-sketch`), Chalkboard (`chalkboard`).
4. **East Asian Traditions**: Shadow Puppetry (`shadow-puppet`), Ukiyo-e (`ukiyoe`), Red Paper-cut (`papercut-red`), Paper-cut Lightbox (`paper-lantern`).
5. **Print & Printmaking**: Risograph Print (`risograph`), Halftone Dossier (`halftone-dossier`), Woodcut Print (`woodcut`), Copperplate Engraving (`engraving`), Silkscreen Travel Poster (`silkscreen-poster`), Printed Long Take (`printed-long-take`).
6. **Graphic & Type**: Swiss Motion Graphics (`swiss-motion`), 60s Spy Title Sequence (`spy-titles`), Art Deco (`art-deco`), Blueprint (`blueprint`), Stained Glass (`stained-glass`), Pictogram Motion (`pictogram-motion`), ASCII / CRT Terminal (`ascii-crt`).
7. **Information & Keynote**: Data Storytelling (`dataviz`), Isometric Infographic (`iso-infographic`), Dark Tech Keynote (`dark-keynote`), Living Screencast (`living-screencast`), Sci-fi Hologram HUD (`hologram-hud`), Transit Map (`transit-map`), Isometric Picture Book (`isometric-picture-book`), Circuit Board (`circuit-board`).
8. **Cartoon & Anime**: 1930s Rubber Hose Cartoon (`rubber-hose`), 80s Cel Anime (`cel-anime-80s`), Sci-Fi Sitcom Toon (`scifi-toon`), Mid-century Cartoon (`midcentury-toon`).
9. **Games**: Pixel RPG (`pixel-rpg`), Microgame (`microgame`), HD-2D (`hd-2d`), Brick Toy (`brick-toy`).
10. **Cinema & Eras**: 1970s Film Title (`silent-film`), Liminal Found Footage (`backrooms`), Game Show (`game-show`).
11. **3D & Miniature**: Tilt-shift (`tilt-shift`), Lowpoly Island (`lowpoly-island`), Memphis Diorama (`memphis-diorama`), Glass Product (`glass-product`), Desktop Flythrough (`desktop-flythrough`), Paper Popup (`paper-popup`).

## How to Work with a Style

1. Read the project's `STYLE.md` and `AGENTS.md`.
2. Inspect the starter template configuration in `listune.json`.
3. Adhere to the grammar rules:
   - **Grammar only, never copy reference content**: no trademarks, copyrighted characters, or direct footage copies.
   - **Color logic**: respect the specified palette (e.g. single signal color in Swiss Motion, Prussian blue and white in Blueprint).
   - **Type & Subtitles**: integrate captions into the composition layout according to the style's specification.
   - **Pacing & Camera**: follow the motion timing (e.g. snap easing on beat for Swiss Motion, drafting order for Blueprint).
4. Run the install command if needed, make your changes, and render with the command in `listune.json`.
